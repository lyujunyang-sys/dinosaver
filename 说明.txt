动态屏保（五张皮肤）
====================

启动：双击这个文件夹里的 start.bat（想放桌面就给它建个快捷方式）
      先弹一个小窗选皮肤 —— 小恐龙 / 字母雨 / 三星系统 / 双摆混沌 /
      柏林噪声流场 / 随机，顺手还有一个「运行期间静音」的勾。选好按「开始」。
      按「取消」= 这次不启动，什么都不会被改。

默认密码：dino
改密码：双击本文件夹里的「设置密码.bat」，按提示输两遍即可
        （只存 SHA256 哈希到 password.hash，不存明文；删掉这个文件就回到默认密码 dino）

关闭：右下角「关闭」按钮 → 输密码 → 确定。按 Esc 也能叫出密码框。
      密码错了会提示；每连错 3 次锁一轮，时长递增 3 秒 → 10 秒 → 30 秒。

五张皮肤
--------
· 小恐龙   —— 原来那个。自己跑、自己跳仙人掌、自己趴下躲翼龙；
              每 700 分昼夜切换一次，最高分存在 hiscore.txt。
· 字母雨   —— 黑客帝国那个。满屏半角片假名往下淌，队头一个白字拖一条
              由亮到暗的绿尾巴；每列速度、长度、起点都不一样，落到底自动重投。
· 三星系统 —— 每次都是现摇的随机三体：随机质量、随机位置、随机速度，
              之后就只有万有引力说了算。没有预设轨道、没有循环动画。
              重的偏蓝白、轻的偏橙红，都拖一条渐隐的轨迹。
              随机三体真正难的不是渲染，是这两件事：
                ① 两颗贴脸掠过时加速度爆表，固定步长会把能量算飞
                   → 自适应步长（跟着最近的一对走）+ 一点软化，
                     实测几千帧下来能量漂移 < 1%
                ② 随机三体迟早会甩出去一颗、剩下两颗结成双星——
                   这是真实结局不是 bug。所以认出被甩出去的那颗，
                   镜头跟住留下的双星，让它自己飞出画面，再淡出重摇。
              一局大约一两分钟，也可能更久，取决于它自己打成什么样。
              三颗星固定三个颜色（金橙 / 冰蓝 / 品红），质量只管大小：
              重的那颗明显大一圈。
              另外：三体最后总会塌成「两颗抱团转、第三颗在远处看戏」，
              那一段没什么可看的。判据是量出来的——最远/最近间距之比，
              中位数 2.6、p75 3.9、p90 6.7，所以 3 倍左右完全是正常缠斗
              （第三颗荡出去还会荡回来），真正的看戏是 8 倍以上。
              现在超过 6 倍且攒够约 6 秒就淡出重摇，实测「看戏」最长
              连续只剩 0.3~1.8 秒。

· 双摆混沌 —— 一根摆挂着另一根摆，最经典的混沌系统之一。这里同时跑 140 个，
              初始角度只差 0.00001 弧度（肉眼绝对分不出），按色相排好队。
              开头它们叠成一条缎带一起甩，然后慢慢劈叉，最后散成一把彩色扇子。
              实测节奏（32fps）：约 13 秒开始看出分岔、24 秒明显散开、
              29 秒完全成扇，50 秒一轮重来。
              积分用 RK4，几分钟下来能量漂移 0.003%。

· 柏林噪声流场 —— 屏幕底下铺着一张看不见的风场，每个点的风向由三维柏林噪声
              决定，第三维是时间，所以风场自己会慢慢变形。几千个粒子顺着风走、
              拖出渐隐的尾巴，像烟、像洋流、像丝绸里的纹路。
              粒子颜色按出生点的噪声取，所以同一股气流里颜色接近，
              画面会分出一条条不同颜色的「流」，而不是一锅彩色。
              粒子数跟着分辨率走（约每 600 像素一个），保证每帧成本大体不变。

选择记在 settings.json（选了「随机」就每次都重摇）。
想跳过选择窗：
    dino_saver.ps1 -Skin dino|matrix|orbit|random   直接指定
    dino_saver.ps1 -NoPicker                        用上次的选择
想先看看某张皮肤长什么样又不想被锁住：
    dino_saver.ps1 -Skin orbit -TestRun 10          跑 10 秒自己正常退出

接管声音
--------
屏保一开就把「系统主音量」那个喇叭按成静音（后台在放的东西一起哑掉），
退出时还原成进来之前的样子 —— 你本来就是静音的，出去还是静音。
选择窗里那个勾可以关掉这个行为，勾的状态也记在 settings.json。
注意：如果进程是被强杀的（任务管理器里结束 powershell.exe），
      静音还原不了，自己点一下喇叭图标取消静音就行。

它做了什么
----------
· 全屏置顶盖住桌面，鼠标静止 3 秒后光标自动隐藏
· 装了一个低级键盘钩子，吞掉这些键：
      Win（左右）、Alt+Tab、Alt+Esc、Ctrl+Esc、Alt+F4、Ctrl+Shift+Esc
  钩子随进程生死，进程一没就自动解除，不改注册表、不留任何后遗症
· 触控板手势三道防线（键盘钩子拦不到手势，手势是驱动/外壳直接处理的）：
    ① 运行期间把三指/四指的滑动和轻点临时设成「无」，退出自动还原
       原值备份在 touchpad_backup.json；万一没还原，跑「恢复触控板手势.bat」
       （就算上次是被强杀的，下次启动也不会把已经归零的值误当成原值）
    ② 每 0.16 秒把窗口重新提到置顶层最上面——「显示桌面」不会最小化我们，
       但会把任务栏抬到我们上面，这一步把它按回去
    ③ 万一被切到别的虚拟桌面，检测到就把窗口挪到当前桌面
· 调 SetThreadExecutionState 阻止显示器息屏和系统休眠
· 后台程序照常跑——这只是一个盖在最上层的窗口，不是真正的 .scr 屏保，
  不会挂起、暂停或影响任何正在运行的程序（除了声音被按静音）

它挡不住什么（说清楚，别指望它是安全措施）
------------------------------------------
· Ctrl+Alt+Del 拦不了，也不该拦——那是系统的安全键，任何用户态程序都碰不到。
  从那里能进任务管理器，结束 powershell.exe 就能强行关掉屏保。
· 任务视图 / Alt+Tab 那个缩略图大网格如果被唤出来，会盖在屏保上面，
  能看到所有窗口的缩略图。那是系统外壳画的，用户态挡不住——
  所以才要靠上面①把手势从源头关掉。
· 这是「防手贱、防误碰」级别的锁，不是防有心人的锁。

可以自己改的参数（dino_saver.ps1 开头「可改配置」那几行）
--------------------------------------------------------
$DefaultPassword   默认密码
$IdleHideCursorMs  鼠标静止多久藏光标（毫秒）
$BlockHotkeys      是否拦截上面那串快捷键，默认开
$BlockGestures     是否运行期间临时关掉触控板三指/四指手势，默认开
$MuteWhileRunning  选择窗里「静音」那个勾的默认值，默认开
$DefaultSkin       还没有 settings.json 时，选择窗默认选中哪张皮肤
$ForceFocus        默认关。改成 $true 会在被切走时强行抢回焦点——连任务管理器
                   都会被抢掉，等于把「万一出问题」的退路也堵死了，慎开
$CoverAllScreens   多显示器时是否把副屏也盖黑

再加一张皮肤
------------
往 skins\ 里丢一个 <名字>.ps1，最后 return 一个哈希表：
    Id / Title / Desc                      选择窗里显示的名字和说明
    Init   = { param($ctx) ... }           返回这张皮肤自己的状态哈希表
    Update = { param($ctx,$st) }           推进一帧（约 32fps）
    Draw   = { param($ctx,$st,$g) }        往 $g 上画一帧
    Theme  = { param($ctx,$st) }           返回 @{Bg=;Fg=}，给「关闭」按钮配色
    Close  = { param($ctx,$st) }           可选，退出前收尾（小恐龙拿它存最高分）
$ctx 里有 W / H / Scale / Rnd / UiK / Dir。状态一律放 $st，别往 $script: 里塞。
然后把名字加进 dino_saver.ps1 里的 $SkinIds。
每帧预算 30 毫秒；字母雨和三星系统的渲染都写在 C# 里（皮肤文件内的 Add-Type，
选中哪张才编译哪张），因为这个量级的绘制 PowerShell 的循环开销扛不住。
实测稳态（目标表面和控件一样用双缓冲，跑满尾巴/满屏之后才计时）：
    2520×1680（这台机器）  小恐龙 9.0、字母雨 11.4、三星 8.5、双摆 5.6、流场 8.7 ms
    1920×1080              小恐龙 6.8、字母雨  5.9、三星 5.3、双摆 3.0、流场 2.9 ms

画得快的两条经验，都是量出来的不是猜的：
· GDI+ 每次 DrawImage 光调用开销就约 10µs。字母雨满屏 2600 个字 = 25ms，
  一帧就没了。所以它不逐字画，而是自己拿一个钉住的 int[] 当像素缓冲把整帧拼好
  （字模烤成「绿字叠在黑底上」的不透明小块，格子互不重叠 → 纯行拷贝，不用混合），
  最后整屏送一次。29ms → 5.9ms。
· 别拿 new Bitmap() 出来的 32bppArgb 位图当画布测性能——它是 GDI+ 的慢路径，
  整屏 DrawImage 要 20ms，而真实控件表面只要 3.75ms。测性能要用 BufferedGraphics。
  三星的背景星空原来烤成整屏位图每帧贴一次，就是踩了这条：改成 Clear + 150 个
  小方块之后 26ms → 9ms。
· 双摆和流场也走像素缓冲，而且连画线都是自己写的（沿长轴走，短轴按小数部分
  分给相邻两个像素 = 抗锯齿；颜色用加色混合，线叠线自然变亮）。
  双摆 140 根 ×（2 根杆 + 64 点尾巴）≈ 9000 条线，交给 GDI+ 是 146ms/帧，
  自己画是 5.6ms。
· 内层循环里别留取模和除法。流场每帧要跑十万次「第 k 档尾巴」的计算，
  而环形下标和亮度权重只跟 k 有关、跟是哪个粒子无关——提到外面先算好，
  28.7ms → 8.7ms。

两个坑（改代码的时候记着）
--------------------------
· .ps1 必须存成「UTF-8 带 BOM」。没有 BOM 的话 Windows PowerShell 5.1 会按
  GBK 解，中文全变乱码、脚本直接语法错误。
· 别把变量起名叫 $script:Skin —— 那是 -Skin 参数（[string] 类型），
  往里塞哈希表会被静默转成字符串，然后调用的时候才炸。
